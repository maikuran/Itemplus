# The Solar — Ore and Equipment Catalogue

## Overworld ores
- Cobalt (コバルト)
- Limonite (リモナイト)
- Jade (翡翠)
- Ruby (ルビー)
- Krillul (クリルル)

## Nether ores
- Sitherian (シテリアン)
- Hellphyros-Remnantius-Forgotina (ヘルファイロス・レムナンティウス・フォルゴティナ)

## Moon ores
- Selenite (セレナイト)
- Lunarium (ルナリウム)

Each of the nine materials has a full tool set (sword, pickaxe, axe, shovel, hoe) and a full armor set (helmet, chestplate, leggings, boots). Both lunar materials also have separate ore drops, ingots, smelting/blasting recipes, repair tags, equipment layer textures and special abilities.

The Selenite set emphasizes low-gravity mobility and night vision. The Lunarium set emphasizes combat durability and strength. Their tools grant mining or combat buffs while held; their armor bonuses scale with the number of equipped pieces.

The complete name Hellphyros-Remnantius-Forgotina is never abbreviated in registry IDs, recipes, tags, translations, or documentation.
